# Bootcamp SQL Review

Repositori ini berisi catatan dan skrip latihan SQL selama proses review materi Data Science.

## Materi yang Diulas
- **DDL & DML**: Pembuatan tabel (`CREATE`), penambahan (`INSERT`), pembaruan (`UPDATE`), dan penghapusan data (`DELETE`)
- **DQL & Filtering**: `SELECT DISTINCT`, operator logika dan rentang pada `WHERE`
- **String Functions**: `UPPER`, `LOWER`, `TRIM`, `LENGTH`, dan penggabungan teks
- **Aggregate Functions**: `AVG`, `MAX`, `MIN`, `COUNT`
- **GROUP BY & ORDERBY**
- **Relational & Nested Queries**: `INNER JOIN`, `LEFT JOIN`, serta *subqueries*
